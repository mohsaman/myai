Secure, local AI

Chat, code, vision, image generation and speech — from open weights on a 32 GB machine. One model answers everything. Nothing is sent to a provider.

The model

Qwen3.8 27B
qwen3.8:27b-mlx · Apple Silicon build
Dense, so every parameter fires on every token. It holds a conversation, writes and reviews code, calls tools, and reads images you paste — a screenshot, a diagram, a table. One model instead of four means no reload when the subject changes.

What runs alongside it

Qwen-Image-2.1
image generation
Makes pictures from a prompt on the same GPU, native 2K, with text inside the image that comes out readable. A diffusion model — separate from the one above, which reads images but cannot draw them.
Kokoro + Piper
text to speech
Kokoro speaks 8 languages with 72 voices; Piper covers 53 more, each a download on first use. A router picks per reply, by detected language.
faster-whisper
speech to text
Dictation into the chat box. Runs locally, so recordings never leave.
nomic-embed-text
retrieval
Turns your documents into vectors so they can be searched and quoted. 0.3 GB — the one job a chat model cannot do.

QuantityValueWhy it is the number that matters
KV cache cost98 KiB/token Measured, not derived. The textbook formula over the model's own architecture gives 34 — wrong by nearly 3×, because the model caches every fourth layer and the runtime adds buffers the formula knows nothing about.
Usable context40,960 What 98 KiB/token buys once the weights are in. Acting on the derived figure would have set a window needing 30 GB on a 24 GB budget.
GPU ceiling~24 GB Of 32 GB unified memory. Exceed it and inference spills to the CPU while still reporting 100% GPU — throughput collapses with no error.
Services9 All on loopback except the web interface and its HTTPS front door.

Every prompt, document, image and recording stays on the machine. For regulated data, a physical guarantee is a different thing entirely from a contractual one.

Honest limits. Frontier models remain better at long, multi-step reasoning, and the context window is bounded by memory rather than by choice. Web search and page fetch are the only things that reach outward — and only when a question needs them, with the sources shown.

Secure, local AI

Chat, code, vision, image generation and speech — built from open-weight models on a 32 GB machine. Nothing is sent to a provider.

The stack

Ollama
Runs the language models and serves them locally
Open WebUI
The browser interface — chat, files, voice, model switching
ComfyUI + SDXL
Image generation on the laptop's GPU
Kokoro
Neural text-to-speech, 72 voices
Whisper
Speech recognition for dictation

The models

Reasoning 30B Mixture-of-Experts
The main conversational model. 30 billion parameters in total, but only about 3 billion activate for any given word — which is how a large model stays fast on consumer hardware.
Vision 7B
Reads images. Paste a screenshot, a diagram or a table and ask questions about what's in it, rather than describing it yourself.
Code 14B
A separate model trained on source code, for writing and reviewing it. Meaningfully better at this than the general model.
Images & speech SDXL + neural TTS
Generates pictures from a text prompt, and reads answers aloud in a natural voice. Both run on the laptop's GPU alongside everything else.

Every prompt, document, image and recording stays on the machine. For regulated data, a physical guarantee is a different thing entirely from a contractual one.

Honest limits: frontier models remain better at long, multi-step reasoning, and the context window is bounded by memory. Web search is the one feature that sends anything outward — and only when asked.
